# Karlens Pierre — Portfolio

Personal portfolio site for Karlens Nikita Pierre, a Computer Science student at Villanova University (Cybersecurity minor) focused on Software Engineering and Cybersecurity.

🔗 **Live site:** [karlensnpierre.netlify.app](https://karlensnpierre.netlify.app)

## Overview

A single-page portfolio summarizing my experience, projects, and technical skills, built as a lightweight static site with a custom "technical blueprint" visual theme — grid lines, drafting-style typography, and a title-block header, nodding to both software architecture and systems/security work.

## Built with

- HTML5 & CSS3 — no framework, hand-rolled layout and design system
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts
- Deployed on [Netlify](https://netlify.com)

## Features

- Responsive single-page layout
- Downloadable resume (PDF)
- Sections covering experience, projects & research, technical skills, leadership, and education

## Run locally

```bash
git clone https://github.com/Kaarsz/portfolio-site.git
cd portfolio-site
open index.html   # or just double-click the file
```

No build step — it's a static site, so there's nothing to install.
